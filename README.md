# event-bus-toolkit

In-memory asynchronous pub/sub event distribution framework for distributed workers.

[![CI](https://github.com/placeholder/event-bus-toolkit/actions/workflows/ci.yml/badge.svg)](#)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Overview
A lightweight, high-reliability Python utility package developed for cloud-native microservices and pipeline health processing.

## Quickstart
```bash
pip install -r requirements.txt
python event_bus_toolkit/core.py
```

## Running Tests
```bash
python -m unittest discover tests
```
